# 🥖 North Star Bakery Website

Hello, fellow coder! This project was built for my **Introduction to Web Development** course. Please be nice!

[🚀 **View Live Website**](https://isaiah987.github.io/sophia-bakery-touchstone/)

---

## What's Included

* **Home (`index.html`):** Welcome banner, seasonal item feature, and audio greeting.
* **Products (`products.html`):** Product card layout showcasing our baked goods.
* **About Us (`about.html`):** Bakery history and a behind-the-scenes video.
* **Contact (`contact.html`):** Simple pre-order form with HTML5 validation.

---

## Features

* **Mobile-First & Responsive:** Stacks cleanly on phones and expands into multi-column layouts on larger screens using Flexbox.
* **Accessible Design:** Features high-contrast colors, logical heading hierarchy, and descriptive alt text for images.
* **Simple Styling:** Built with pure CSS using a 4-color bakery palette and 2 Google Fonts (*Lora* and *Lato*).
